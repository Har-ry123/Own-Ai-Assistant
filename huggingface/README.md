# Hariom AI Assistant

A vector database written from scratch in Java, comparing **HNSW**, **KD-Tree**
and **Brute Force** search, with RAG question answering powered by Ollama
(`nomic-embed-text` + `llama3.2:1b`).

Source code: <https://github.com/Har-ry123/Own-Ai-Assistant>
